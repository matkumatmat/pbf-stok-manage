# PBF STOK MANAGE

Sistem manajemen inventori dan pelacakan batch untuk distributor farmasi (PBF - Pedagang Besar Farmasi).

## Fitur Branch pd-1: Batch Record di Spreadsheet

Branch ini mengimplementasikan fitur **ekspor batch record ke spreadsheet**, yang memungkinkan pembuatan ledger transaksi batch untuk keperluan audit dan kepatuhan regulasi farmasi.

### Fitur Utama:
- Pencarian dan detail produk berdasarkan kode atau nama
- Pelacakan batch dengan informasi manufaktur dan kedaluwarsa
- Ekspor riwayat transaksi batch ke Google Sheet yang terformat
- Perhitungan stok berjalan (running stock) per batch
- Link shareable dan download XLSX untuk dokumentasi
- Tracking penerimaan dan distribusi barang per batch

## Teknologi

- **Google Apps Script (V8 Runtime)**
- **Google Sheets** sebagai database
- **CLASP** untuk deployment
- **Tailwind CSS** untuk UI
- **Lucide Icons** untuk ikon
